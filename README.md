Staff software engineer in Istanbul. More than a decade of end-to-end delivery on client platforms, as developer and tech lead.

Since 2025 most of my work has been how a team develops with AI. On an enterprise Adobe Experience Manager platform I introduced the agent-based workflow the team develops on: Claude Code with Jira and Figma MCP integrations, GitHub CLI automation, custom skills for auditing, documentation and component generation, and layered repository rules with maintained memory that make the coding agents generate against the design system's components and tokens.

It wasn't the first attempt. Cursor and GitHub Copilot's agent mode were tried on the same codebase and dropped, because neither was performant enough and both needed more human input to reach production quality. AEM is a stack the models have seen very little of, which is most of the reason.

Since it held, pull request volume roughly doubled and median time to merge went from 3.3 hours to 2.7. The number of changes merged without a human review doubled along with the volume: the share held, the count didn't. Review capacity is the constraint now, not how fast anyone writes code.
